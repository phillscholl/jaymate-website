A few things to know.

Does Jaymate replace Jamf Pro?

No. Jaymate connects to your existing Jamf Pro instance and offers a native interface for selected inventory, diagnostic, and administrative tasks. You still need Jamf Pro and the required permissions.

Is this an official Jamf app?

No. Jaymate is an independent project by Philippe Scholl. It is not affiliated with or endorsed by Jamf.

Can Jaymate start software updates?

The Software Updates module is read-only. It helps you understand plans, events, and errors; it does not initiate updates.

Can I download Jaymate now?

Not yet. Only the website is public at this stage. Download and setup details will appear here when the app is available. You can follow the website repository for updates.
