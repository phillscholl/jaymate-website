# Jaymate website

The public marketing website for Jaymate, a native Mac fleet manager by Philippe Scholl.

Visit https://phillscholl.github.io/jaymate-website/

This repository contains only the website. The macOS application source is private and is not included. No public app download is available yet.

## Editing and publishing

Edit `index.html`, `styles.css`, or `script.js`. Assets are stored beside these files. GitHub Pages publishes the root of the `main` branch automatically after a commit. No build or dependencies are required.

The device illustration uses fictional sample data. Appearance follows the system setting with an optional local override. No analytics or external fonts are loaded.
